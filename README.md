# Stallone

**Stallone** is the project. **Arnold** is the agent.

An autonomous 24/7 coding agent where Gemini is the brain and Ollama models are the workers.
Arnold plans, architects, delegates code generation to local Ollama models, surgically applies
the results, verifies via git, and ships — with no approval gates on local work.

## Status

Planning phase. See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the full design.
See [`docs/WHY_STALLONE.md`](docs/WHY_STALLONE.md) for why this exists.

## Built on

Everything LocalClaw proved works — the DB, memory, RAG, knowledge graph, skills, Telegram,
MCP servers, sandbox — rebuilt around a Gemini-driven tool loop instead of a static planner.

## The difference

LocalClaw planned once and stepped away. Arnold never steps away.
